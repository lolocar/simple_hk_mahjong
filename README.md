# 港式麻雀（Web 3D）

四人港式麻雀（推倒胡）Web 遊戲，Three.js 3D 沉浸視角，繁體中文界面。

## 功能
- 144 張牌（萬/筒/條/東南西北中發白 + 8 張花牌，摸到補花）
- 吃、碰、槓（暗槓／加槓）、胡
- Claim 優先級全局裁決：胡 > 槓 > 碰 > 吃；同級按座位順序（由出牌者下家起數）
- 握有 3 張同牌時「槓」與「碰」同時提供（碰用 2 張留 1 張），與吃一併列出供選擇
- 一炮多響：多家可胡時取離出牌者最近的一家
- 搶槓胡：加槓（補槓）瞬間可被別家搶胡，過牌後槓才成立
- 槓後嶺上補牌（從牌牆尾端取）
- 番種計算：七對、清一色、混一色、字一色、大/小三元、大/小四喜、碰碰胡、平胡、
  門風刻、圈風刻、自摸、槓上開花、搶槓胡、海底撈月、底胡
- 積分模式（一二蚊・半銃制・辣辣上，規則參考 [廣東麻雀籌碼計法](https://zh-yue.wikipedia.org/wiki/%E5%BB%A3%E6%9D%B1%E9%BA%BB%E9%9B%80%E7%B1%8C%E7%A2%BC%E8%A8%88%E6%B3%95)）：開局每人 1000 分；單份金額 = 2^番（0番=1, 1番=2, 2番=4…）；
  出銃者出雙份、其餘兩家出單份，自摸三家各出雙份（自摸以雙份體現，計番時不再重複計「自摸」番）；與門風相符的花牌逐張計 1 番；
  任一家積分 ≤ 0 即整場結束並排名，點「重新開場」重置積分
- 圈數制（參考 [香港麻雀](https://zh.wikipedia.org/zh-tw/%E9%A6%99%E6%B8%AF%E9%BA%BB%E9%9B%80)）：一圈 = 莊家完整輪莊一次（東位→南位→西位→北位），圈風固定於整圈之內（東圈→南圈→西圈→北圈），只在北位莊家過莊／流局回到東位時才進下一圈；莊家胡牌連莊、閑家胡或流局過莊；一圈結束時積分不重置、繼續累計；滿四圈（完整輪莊四次）整場結束並排名（任一家積分 ≤ 0 即積分見底，優先結束）
- 記分板（右上角）：按積分由高到低排列，每行顯示排名、玩家、積分、胡牌數、放炮數，積分字體放大
- 三個 AI 對手（簡單策略：留搭子、碰胡優先）
- 3D 桌面：玩家手牌、其他玩家牌背、中央打牌區、吃碰槓展示、花牌區
- 東南西北門風標記平放桌面（各家正前方置中、貼近桌沿；字頭朝桌心，該家低頭讀自己那個字是正的）
- 補花 / 吃 / 碰 / 槓 時，在該家桌邊彈出說話氣泡提示（3 秒後消失；暗槓不顯示牌名）
- 沉浸視角（玩家0背後略高位置）

## 運行
```bash
npm install
npm run dev
```
打開 http://127.0.0.1:5173

## 構建
```bash
npm run build
```

## 操作
- 點擊 3D 手牌：出牌
- 摸牌階段：點擊桌面空白處摸牌（手牌右側有「摸牌」提示）
- 吃/碰/槓/胡 按鈕：有人出牌時按需顯示；優先級低於別家（如別家可胡而您可碰）時自動由別家執行
- 自摸胡：摸到胡牌時出現紅色「自摸胡！」按鈕
- 暗槓／加槓：手牌 4 張同牌、或已有碰子且握有第 4 張時出現對應按鈕（加槓可能被搶槓胡）
- claim 決策有 10 秒倒計時，超時自動「過」
- 結算面板：顯示番種與總番數、一二蚊結算（單份金額、各家增減）、自摸/放炮說明與最新積分；整場結束時顯示排名，可「再玩一局」或「重新開場」

## 文件結構
```
src/
  game/
    tiles.ts    # 牌定義、排序、計數
    hand.ts     # 胡牌判定、番數計算、聽牌
    score.ts    # 積分結算（一二蚊・半銃制、門風花牌番、排名）
    game.ts     # 遊戲狀態機（發牌/摸牌/出牌/吃碰槓胡、積分與圈數）
    ai.ts       # AI 策略
  three/
    board.ts    # Three.js 場景、牌紋理、布局
  ui/
    ui.ts       # 操作按鈕、信息欄、結算面板
  main.ts       # 整合入口
```
